# NaijaDeals Project Workflow

A skill for repository discovery, architecture mapping, incremental implementation, debugging, and concise handoffs.

## Usage
Use when starting a new task, debugging an issue, or finalizing a deliverable.

## Procedures
1. **Discover**: Identify relevant files, routes, and services for the task.
2. **Map**: Draft architecture changes if needed.
3. **Implement**: Perform incremental changes, verified by tests.
4. **Handoff**: Generate a concise report:
   - Branch
   - Verified changes
   - Tests
   - Remaining blockers
   - Next action
5. **Distinguish**: Clearly label implemented vs verified vs deployed status.

## Verification
- Task achieved without regression.
- Relevant tests passed.
- Concise, evidence-backed handoff drafted.
