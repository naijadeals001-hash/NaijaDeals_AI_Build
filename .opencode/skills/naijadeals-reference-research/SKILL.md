# NaijaDeals Reference Research

A skill for public product research and authorized artifact inspection.

## Usage
Use when researching industry standards (Uber/Bolt for rides, Amazon/Jumia for commerce) to inform NaijaDeals features.

## Procedures
1. **Research**: Identify and analyze workflows.
2. **Observe**: Record observed workflows, sources, dates.
3. **Imply**: Map observations to implementation requirements.
4. **Separate**: Observations from assumptions.

## Constraints
- Use REA for authorized inspection.
- Do not claim APK analysis reveals proprietary server-side dispatch or pricing logic.
- Implement original code based on research; do not bypass access controls or copy proprietary code.
